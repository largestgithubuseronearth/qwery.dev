Property

IdeVcsCloneRequest:branch-model

Declaration 

property branch-model: Gio.ListModel [ read ]

Description

The “branch-model” contains a GListModel of IdeVcsBranch that represents the names of branches that may be available on the peer.

This model is not automatically updated until ide_vcs_clone_request_populate_branches() is called. This is to make it clear to the user that it is being done in response to an action (such as showing a popover) since user/password information may be requested from the user.

The UI may use this to show a popover/selection of branches for the user to select.
